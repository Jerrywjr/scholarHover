# 知阅 · 文献悬停助手

在支持的 HTTPS 网页链接上停留片刻，先看清论文，再决定是否打开，包括 Google Scholar、Nature 和 arXiv。桌面 Chrome 扩展，用户自带模型 API Key，无产品账号和自建后端。本地 0.5.0 工作版本新增默认关闭的工具栏开关，支持简体中文、英语、法语和德语，保留本机预览归档与主动收藏后的后台补全，并从目标论文链接读取真实摘要。

[English README](README.md)

**0.5.0 为本地试验版本，尚未发布。** 公开下载仍为 0.4.0。 从 [GitHub Releases](https://github.com/Jerrywjr/scholar-hover/releases/tag/v0.4.0) 下载后手动安装，尚未提交或上架 Chrome Web Store。真实 Scholar 匹配、翻译质量与筛选价值，以及四种语言的人工和母语使用者审核仍未完成。[0.4.0 测试报告](docs/test-report-0.4.0.md) 记录了自动化检查及其适用范围；不能把构造页面或元数据派生输入的测试结果当作真实 Scholar 匹配准确率。

## 安装与配置

1. 试用本地 0.5.0 时，从当前代码构建并加载 `dist`，或解压本地提供的 `scholar-hover-0.5.0.zip`。公开版本仍在 [v0.4.0 发布页](https://github.com/Jerrywjr/scholar-hover/releases/tag/v0.4.0) 下载 [scholar-hover-0.4.0.zip](https://github.com/Jerrywjr/scholar-hover/releases/download/v0.4.0/scholar-hover-0.4.0.zip)，解压到固定目录，不要只双击 ZIP。请选择扩展安装包，而非 GitHub 自动提供的 Source code 源码压缩包。源码构建后也可直接使用本项目 `dist` 目录。
2. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角“开发者模式”。
3. 选择“加载已解压的扩展程序”，选择包含 `manifest.json` 的解压目录或 `dist`。
4. 点击扩展图标打开工具栏弹窗，再选择“设置”，选择界面语言和生成语言，填写模型 API 基地址、模型名称、API Key；阅读外发说明并勾选同意，尚未被已有 HTTPS 授权覆盖时授予模型域名访问权限；已有授权不替代外发同意。
5. 本地 0.5.0 返回工具栏弹窗，把悬停开关切为 ON，授予可选的所有 HTTPS 网站访问权限（`https://*/*`），再悬停或聚焦支持页面的链接 500 毫秒。已打开的支持页面无需刷新即可注入脚本；公开 0.4.0 下载仍仅支持 Scholar。

API 地址填写包含版本路径的**基地址**，例如服务商提供的 `https://api.example.com/v1`；程序会追加 `/chat/completions`。不要填写完整的 `/chat/completions` URL。模型名必须使用服务商给出的 API 模型标识。目前仅支持 Chat Completions 纯文本非流式接口，不承诺兼容所有模型服务。连接测试会发起一次很短的模型请求，可能计费。

已发布的 0.4.0 发布页同时提供该版本扩展 ZIP 的 [SHA-256 校验文件](https://github.com/Jerrywjr/scholar-hover/releases/download/v0.4.0/scholar-hover-0.4.0.zip.sha256)。

升级已解压扩展时，把新包解压到原先加载的固定目录，在扩展管理页点击重新加载，本地 0.5.0 在工具栏重新开启；公开 0.4.0 则刷新 Scholar 页面。换一个目录重新加载可能会被视为另一扩展实例，需要重新配置。0.4.0 会把现有生成缓存迁入本机 IndexedDB 归档，归档事务提交成功后才清理旧副本；迁移失败保留原始记录。已有配置和收藏保留，译文仅在论文内容与模型配置指纹一致时复用。

本地 0.5.0 首次安装或首次从 0.4.x 升级后默认 OFF；之后重新加载或重启浏览器会保留开关状态。工具栏切为 ON 时申请 `https://*/*` 可选权限，访问范围是所有 HTTPS 网站，不再只是某一家出版社，用于读取悬停链接文字与目标论文元数据。OFF 停止新的预览，保留已有归档与收藏，已发起任务可能继续完成。`chrome://`、Chrome 应用商店、内置 PDF 阅读器和限制扩展访问的网页不支持。模型调用仍需已有配置与外发同意。

## 语言与使用方式

界面语言和生成语言分别设置。例如，界面可用法语，标题、摘要译文和一句话概述可用德语。两项均默认简体中文，旧版缺少语言字段或存储语言无效时也回退为简体中文。仅修改语言设置会保留原有密钥。

只改界面语言会继续复用已有生成缓存；改变生成语言会使用单独的缓存条目，因此英文结果不会被当作德文结果使用。原始标题、原始摘要及文献元数据保持原样，译文和概述按所选生成语言显示，不会用译文覆盖原始来源文本。

- 悬停先检查本机归档，已有且与当前配置一致的元数据和译文一起显示。归档按规范化后的精确目标 URL 识别，同一 URL 的不同链接文字可复用预览。首次查看的论文优先读取该目标原文链接，再按需要补充索引信息；来源查询和模型完成后更新卡片。首次补全速度取决于网络与服务商，不能承诺即时生成。当前结果页的“已查看”“已缓存”等徽标只查询本机状态，不会为全部结果发起外部请求。
- 卡片统一位于页面右侧，宽度 420 px（窄窗口自动限制），默认占满浏览器可见高度。拖动上下边框可调整高度，“恢复全高”可复位。正文支持滚轮、触控板和键盘滚动，标题及操作区保持可访问。鼠标离开标题后面板仍保留；未固定时点击其他位置可关闭；关闭按钮和 Esc 始终可用，固定后可专注阅读。
- 模糊匹配需要手动选定候选。明确预印本不会静默使用正式发表版；无法确认时保留原页面信息。缺少摘要只允许翻译标题，不编造摘要或研究概述。
- “匹配后自动生成”可关闭，改为点击生成。手动点击后自动固定卡片，按钮显示“正在生成…”并暂时禁用；结果返回后展示译文。底部持续显示进度或具体错误，失败后按钮恢复为“重试生成…”，也可通过始终可见的“设置”检查配置。连接测试最多等待 25 秒，完整生成的响应开始与内容读取分别最多等待 90 秒；失败不会自动循环调用模型。鼠标在元数据或缓存返回前已经离开论文时，插件不会在后台启动新的自动生成，重新进入卡片后才会继续。
- 默认 Key 仅保留本次浏览器会话；重启后重新填写。勾选本机保存后会持久保存，但这不是系统密码保险库。更换模型服务域名会清除旧模型 Key，必须重新填写；OpenAlex Key 不会发给模型服务。
- 预览元数据、匹配候选和生成结果保存在本机 IndexedDB 归档中，不按时间、200 条或 4 MiB 自动淘汰；仍受浏览器实际存储配额限制。论文内容、接口地址、模型、生成语言和提示词版本决定译文能否复用；不同模型或生成语言分别保存，不跨用户同步。设置页可清空预览与生成归档或密钥。

“重新读取摘要”重试来源读取，“重试生成”只使用当前论文文本重试模型。旧预览中没有摘要、候选或人工确认的记录，包括已存的 HTTP 429 失败，再次打开时可进入新读取流程；不清空完整摘要或已有付费译文。取得新摘要后，翻译输入发生变化，旧的标题译文不能充当摘要译文。已收藏的失败条目可手动重试补全。取得摘要后的模型调用仍遵循生成设置、外发同意和配置。

## 缓存文章与批量导出

1. 卡片刚打开即可点击“缓存本文”。先把页面已有的论文信息存入本机，不等待元数据或模型返回；保存成功后进入后台队列，继续匹配论文、查找摘要并补全译文与要点。主动保存也表示要求补全该篇文章，即使“匹配后自动生成”已关闭；调用模型仍需已有外发同意、服务配置、域名权限和有效 Key，可能产生费用，已有可用结果会直接复用。再次保存同一结果保留首次顺序，不会自动重启失败或中断的任务。
2. 点击“下载缓存文章”打开独立管理页，查看补全进度、配置或失败原因；匹配不确定时需先确认候选。处理失败原因或配置后，点击“重试补全”，模型失败不会自动重复调用。可删除条目、拖拽排序，或用上移/下移按钮。初始顺序为点击缓存的顺序；最终导出按整理后的顺序重新编号 1、2、3。
3. 点击管理页顶部的“下载缓存文章”。一个 `articles.md` 包含名称、作者、年份、期刊、原摘要、译文、摘要要点、来源、APA 风格引用及 BibTeX；同时尝试下载 `1-标题.pdf`、`2-标题.pdf` 等。尚未补全也可以导出，管理页会提示未完成数量，缺失字段继续明确标记。文件保存在浏览器下载目录下的 `ScholarHover/时间-批次/`，每次导出是固定快照，之后调整顺序或补全内容不会改写已导出的文件。
4. 管理页按条目显示真实下载状态。没有已知 PDF、返回登录 HTML 或下载中断时明确提示；自动打开本批次首个失败条目的原文页面，其他失败项可点击原文/认证链接。完成登录、机构认证或验证码后可手动重试。插件不自动填写凭据或绕过认证；若只有文章页面、没有直达 PDF，需在原文页面自行下载。只采用匹配记录的主要出版版本，不静默下载其他预印本。

浏览器仍运行时，关闭网页标签页后后台补全会继续。浏览器或扩展后台重启后，排队任务和未完成的元数据查询会恢复；已经进入模型生成的任务优先复用已有匹配结果，没有可用结果时标为“已中断”，需人工重试，因为上次请求可能已经计费。浏览器重启后，会话 Key 需要重新填写。删除条目后，旧补全任务不能把它重新添加，或覆盖后来重新收藏的条目。

收藏独立保存在本机，最多 200 篇、4 MiB，不自动到期；该限制不用于预览与生成归档。“开始新的检索”会清空当前收藏（操作前确认），清空归档不会影响收藏。已下载文件不会因删除收藏而被删除。引用按现有元数据生成，缺失的卷期、页码不补造；BibTeX 使用通用 `misc` 类型，正式使用前请核对。`downloads` 权限用于上述显式下载及该批次状态检查。

## 数据与边界

检查本机归档后读取悬停链接的目标网页，核验论文身份与明确摘要。arXiv `/abs/`、`/pdf/` 和 `/html/` 链接转换为摘要页并保留 `v2` 等明确修订版，不用索引中的发表版或另一修订版替换。Nature 提取要求可核验论文身份及明确 Abstract 摘要区；其他公开 HTML 页面需要论文引用元数据或 `ScholarlyArticle` 信息及明确摘要。普通描述和搜索片段不当作完整摘要。没有论文元数据的普通链接不以链接文字做索引标题搜索，可立即保存，主动点击只翻译标题，不编造摘要。已识别论文可由 [OpenAlex](https://help.openalex.org/api/) 和 [Crossref](https://www.crossref.org/documentation/retrieve-metadata/rest-api/) 按身份规则补充。来源由程序记录，模型不能修改。服务可用性与限额仍由服务商决定，这些解析支持不证明覆盖所有出版社。

工具栏明确开启并授予所有 HTTPS 网站可选 `https://*/*` 权限后，插件增强支持的 HTTPS 网页链接，不自动搜索或翻页；原文下载仍只在管理页主动导出时进行。隐私说明提供 [简体中文](docs/privacy.md)、[English](docs/privacy.en.md)、[Français](docs/privacy.fr.md) 和 [Deutsch](docs/privacy.de.md)。安装不会自动获得所有网站权限，开启悬停时会申请这一范围。公开原文 HTML 请求不发送 Cookie、登录凭据或 API Key，由 offscreen 隐藏页在本机解析；密钥不写入网页，整页不发给模型，只在已有同意后发送标题、真实取得的摘要与指令。不执行网页脚本、登录流程或跳转，不提取任意 PDF 文本。原有显式 PDF 导出不变，Chrome 可能携带该来源站点已有 Cookie。

本版不包含 JIF、PDF 精读、文献库同步、收费系统或自动遥测。JIF 必须取得适用于公众产品的数据授权后另行接入，期刊指标也不能替代单篇论文评价。

## 开发与复现

需要 Node.js 22 或更新的受支持版本，使用 npm 锁文件安装。在仓库的 `scholar-hover/` 子目录运行以下命令。安装依赖和浏览器需要联网；依赖齐全后，下列测试使用本地夹具。

```sh
npm ci
npm test
npm run test:corpus
npm run typecheck
npm run build
npx playwright install chromium
npm run test:e2e
npm run package
```

`test:e2e` 在临时、隔离的 Chromium 配置中加载真实 `dist` 扩展，使用离线 Scholar、普通 HTTPS 页面和 API 响应夹具，不调用真实 Scholar 或付费模型。权限申请与拒绝逻辑有自动测试，浏览器测试在受控权限边界预先授予 HTTPS 权限，尚未验证真实 Chrome 授权对话框。本次结果见 [0.5.0 测试报告](docs/test-report-0.5.0.md)。截图和计时保存于 `test-results`。先构建再运行 E2E；修改源码后需重新构建。历史 0.4.0 验证结果与适用范围见 [0.4.0 测试报告](docs/test-report-0.4.0.md)。

`npm run package` 输出可解压加载的 ZIP 与 SHA-256 校验文件，不签名、不上传商店。[商店介绍](docs/store-listing.md) 仍为草稿；GitHub 开源试验版、商店提交和人工评估的状态见[发布状态与剩余检查](docs/release-readiness.md)。

## 人工评估入口

[100 条固定真实文献样本](evaluation/corpus-100.json) 已保留来源和采集时间，但其中的 Scholar 输入是从元数据派生，**不是从 Scholar 观察得出的人工真值**。请按 [评估说明](evaluation/README.md) 核对并记录实际输入、两位审核者结论，以及翻译中的数字、否定和结论强度。该语料不证明任何一种语言已经完成人工检查或母语使用者审核。

```sh
node scripts/collect-corpus.mjs
node scripts/evaluate-corpus.mjs
node scripts/evaluate-corpus.mjs --require-human-review
```

默认采集命令只检查已有文件；只有显式 `--refresh` 才重新联网采集。人工审核未完成时，评估器报告 `NOT VALIDATED`，严格模式以退出码 2 结束。目标为 100 条中至少 80 条正确自动匹配、零错误自动匹配，摘要覆盖率独立报告；这些是验收目标，不是已取得的结果。

历史检查见 [0.3.1 慢模型请求修复报告](docs/test-report-0.3.1.md)、[0.3.0 收藏与下载报告](docs/test-report-0.3.0.md) 和 [0.2.0 多语言报告](docs/test-report-multilingual.md)，各自描述当时版本，不代表当前发布状态。
