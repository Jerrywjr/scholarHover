## 人工与真实环境验收状态

已通过 OpenAlex 公开 API 收集 100 条有来源链接和采集时间的真实文献元数据，来自四个主题查询，各 25 条，实际年份范围为 2015–2024。100 个 DOI 唯一；71 条原始记录含摘要字段。这一 71/100 仅描述采集文件，不是插件在 Scholar 中成功取得摘要的覆盖率。

当前人工审核 **0/100**，真实 Scholar 自动匹配评估 **0/100**，翻译人工检查 **0/100**，真实环境计时 **0/100**。种子明确标记为从元数据派生，评估脚本报告 **NOT VALIDATED**；严格模式返回退出码 2。因此，至少 80 条正确自动匹配、零错误自动匹配的目标尚未检验。这个便利样本也尚未证明充分覆盖异常情况或不同学科，需要人工补充和核对。

以下验收仍需后续试用完成：

- 在真实 Scholar 页面核对固定样本和异常案例，独立报告正确自动匹配、错误自动匹配、拒识和摘要覆盖率。
- 使用目标模型服务与真实 Chrome 授权流程，验证连接、费用提示、会话重启和服务兼容性；人工检查数字、否定、限定条件和结论强度。
- 在约定验收设备上测量真实页面已有信息及缓存显示的 P95，并分别记录文献和模型请求耗时。
- 按 `evaluation/README.md` 的方案开展 8–12 人交叉试用，比较筛选时间、误选、漏选和配置成功率。没有执行招募或联系参与者。

公开发布需先审阅这些结果和发布材料。未上传 Chrome 商店，未启用 JIF；商店联系人和公开隐私地址仍需发布者提供。

## 复现与交付

在项目根目录执行：

```sh
npm ci
npm test -- --reporter=json --outputFile=test-results/unit.json
npm run test:corpus
npm run package
npx playwright install chromium
npm run test:e2e
node scripts/evaluate-corpus.mjs
```

`release/scholar-hover-0.1.0.zip` 可解压后通过 Chrome 开发者模式加载。当前安装包 SHA-256：
