# 0.2.1 界面回归报告

日期：2026-09-16。本版根据用户试用反馈修复拖动、摘要滚动和生成反馈。交付为本地测试包，GitHub 公开发布继续等待用户确认。

## 行为与修复依据

- **拖动：**按住标题栏移动卡片，开始拖动后自动固定；拖动位置受浏览器可见区域限制。固定、关闭等按钮不会触发拖动。向上移动时保持原有高度上限，避免长卡片向上拖后自动长高、无法再向下移动。
- **滚动：**正文形成独立的滚动区域，摘要原文和译文均可滚动到末尾；标题栏、状态与底部操作保持可见。滚到正文边界不会继续滚动 Scholar 页面。重绘时保留展开状态和阅读位置；内容区可以用键盘聚焦并滚动。
- **生成反馈：**手动点击会固定卡片，立即显示“正在生成…”，并禁用重复请求按钮。成功后展示结果；失败后恢复可点击的“重试生成…”按钮并显示具体错误，设置入口始终可用。请求过程中的固定切换不会掩盖生成进度。仅刷新未变化的设置时不重建卡片，避免浏览器重新获得焦点时替换正在按下的按钮。

旧版浏览器回归明确复现了摘要末尾和底部操作被裁切：外层高度受限，但内部没有有效的滚动布局。单元测试复现了请求中按钮仍可点击、失败缺少重试标识、焦点刷新替换按钮、重绘丢失阅读位置及缺少拖动行为。5 条新回归先在旧实现失败，再在修复后通过。

用户实际环境中首次点击“无效果”的唯一原因尚未确认。本版修复的是可复现的界面问题，并验证了完整手动生成流程；这不等同于已验证用户使用的模型服务、密钥或网络。

## 安装包与复现

安装包：`release/scholar-hover-0.2.1.zip`。SHA-256：

```text
fc9006220a6c0d541d44e9ececc3895b7165299098ccaf1a21f9bcb20691ed9f
```

从 0.2.0 升级时，将新包解压覆盖到原加载目录，在 `chrome://extensions` 点击该扩展的重新加载，再刷新 Scholar 页面。本次升级不主动清除配置或生成缓存；旧版本测试包保留。

依赖安装后，从 `scholar-hover` 目录复现：

```sh
npm test -- --reporter=json --outputFile=test-results/unit.json
npm run test:corpus
npm run build
npm run test:e2e
node scripts/package.mjs
```

界面截图中的文献与译文是测试夹具，不代表真实模型输出质量。首次配置、Chrome 原生授权对话框及用户模型服务仍需试用确认。
