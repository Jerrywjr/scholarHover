# 0.3.1 慢模型请求修复报告

日期：2026-09-16。此修复针对设置页连接测试成功、完整摘要生成固定在 25 秒失败的问题。

## 原因与修复

连接测试只发送短 Ping；完整生成发送论文标题与原摘要，并要求完整摘要译文及一句概述。两者原先共用 25 秒上限。Qwen 27B 等较慢模型可以在连接测试中快速响应，但完整生成超过 25 秒。

0.3.0 的常驻右侧面板还有一个放大条件：鼠标离开论文后，迟到的元数据或缓存结果仍会启动自动生成。连续浏览会造成不同论文并发请求。

0.3.1 只在读者仍停留于论文、进入侧栏、固定侧栏或手动点击时启动生成。离开后返回的元数据仍可显示，但不会自行产生新模型请求。完整生成改由扩展自有的隐藏文档与专用 Worker 执行，并定期维持 MV3 后台生命周期；响应开始和完整正文读取分别最多等待 90 秒。连接测试仍保持 25 秒。失败不自动重试。

Chrome 官方说明：扩展 service worker 中等待超过 30 秒才收到 fetch 响应可能导致 worker 终止，因此不能只在原后台代码中把数字改成 90 秒。参见 [扩展 service worker 生命周期](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle)和 [Offscreen API](https://developer.chrome.com/docs/extensions/reference/api/offscreen)。

## 验证范围

自动测试共 214 项通过，覆盖：40 秒后才开始的非流式响应、响应正文延迟 40 秒、两阶段 90 秒超时、连接测试 25 秒、离开标题后延迟元数据/缓存不触发生成，以及返回侧栏后恢复生成。构建后的真实 MV3 浏览器检查 74 项通过，其中专用 Worker 经本机 HTTPS 模型夹具完成一次 31 秒后才返回的请求；未调用用户模型或密钥。

安装包为 `release/scholar-hover-0.3.1.zip`。公开发布仍等待试用确认。
