# Scholar Hover v0.4.0

Decide what to read without opening every paper. This first public, experimental release keeps source-linked previews beside Google Scholar results and turns promising papers into an ordered reading list.

## What you can do

- Preview paper metadata, translate titles and abstracts, and read a one-sentence summary based on the original abstract.
- Revisit generated information from the local archive, even when you never explicitly saved the paper. Current content and model settings determine reuse.
- Save immediately while metadata and translation complete in the background. Closing the search tab does not stop saved jobs while the browser remains open.
- Restore Not viewed / Viewed / Saved indicators after restart; confirm uncertain matches and manually retry failed or interrupted completion.
- Reorder saved papers and export one Markdown file with APA-style references and BibTeX; attempt available original PDFs with matching numbered filenames.
- Choose English, Simplified Chinese, French or German independently for the interface and generated text.

## Install or upgrade

Download `scholar-hover-0.4.0.zip` from the assets below, extract it, and load the folder at `chrome://extensions` with Developer mode enabled. Requires desktop Chrome 120+. This is an unpacked extension, not a Chrome Web Store release. The `.sha256` asset verifies the ZIP.

For an existing installation, replace files in the same folder, reload the extension, then refresh Scholar. Existing generated records are migrated into the archive. Avoid uninstalling or changing the loaded directory if you want to keep the original extension's settings and data.

Bring your own model API key. Model calls may be billed by your provider and require configuration and consent to send the paper title and available abstract. Supported requests use non-streaming Chat Completions; provider compatibility varies. Keys are session-only by default, with optional local persistence. Choosing Save paper explicitly requests background completion even when automatic hover generation is disabled, and may call and be billed by the model provider.

## Validation and limits

287 unit/DOM tests and 87 browser checks passed using local fixtures. Browser coverage includes saving before metadata arrives, completion after closing the search tab, restoring an unsaved translation after a real browser restart without a model key, and real numbered downloads from a local test server. These checks do not establish real-world matching accuracy, translation quality or faster literature screening. Hosted GitHub Actions is not enabled because the publishing credentials lack workflow-writing permission; an inactive workflow example is included in the source.

Abstracts and PDFs are not always available. No abstract means no abstract summary; uncertain matches require confirmation. Institutional sign-in and CAPTCHA remain user actions. Generated references need review before formal use. The saved reading list is limited to 200 papers / 4 MiB; preview archives have no automatic expiry or count eviction but remain subject to browser storage limits. A model request interrupted by restart may already have been billed and requires explicit retry if no result was saved.

## 中文发布说明

知阅的第一个公开开源试验版：在 Google Scholar 结果旁预览有来源的论文信息，保留已经生成的译文，并整理成可导出的阅读清单。

本版支持预览自动归档、立即缓存后后台补全、重启恢复三种查看状态、候选确认与失败手动重试；可以排序后导出 Markdown、APA 风格引用、BibTeX 和同编号的可用原文 PDF。界面与译文分别支持中文、英文、法语和德语。

下载附件中的 ZIP，解压后在 Chrome 扩展页开启开发者模式并加载解压目录。升级请覆盖原目录后重新加载，再刷新 Scholar；不要卸载重装或换目录，以免失去原实例的本机数据。模型 API Key 由用户提供，配置并同意外发后才能调用，服务商可能计费。即使关闭悬停自动生成，主动“缓存本文”仍会请求后台补全并可能调用模型。重启后中断的模型请求可能已经计费；没有已保存结果时需手动重试。

287 项单元/页面测试和 87 项浏览器检查使用本地模拟服务完成，不代表已证实真实匹配准确率、译文可靠性或筛选效率。摘要覆盖、原文获取、模型兼容性仍受外部服务影响；机构认证由用户完成。由于发布凭据没有工作流写入权限，GitHub Actions 暂未启用，源码附手动启用示例。欢迎通过 Issues 提交可复现的问题，请勿附上 API Key 或私有论文内容。
