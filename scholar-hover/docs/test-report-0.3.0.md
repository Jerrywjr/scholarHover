# 0.3.0 右侧面板、收藏与下载报告

日期：2026-09-16。交付为本地安装测试包，GitHub 公开发布继续等待用户试用确认。

## 本版行为

预览统一贴在页面右侧，宽度 420 px（受窄窗口宽度限制），默认占满浏览器可见高度。上下边框支持鼠标拖动及方向键调节，“恢复全高”复位。正文独立滚动；面板不会因鼠标穿过页面空白区域提前消失。调整边框会自动固定，关闭和 Esc 仍可使用。

“缓存本文”保存当前后台核验记录及已有生成结果。重复保存更新同一条目且保留首次保存位置；没有摘要或译文时不补造。“下载缓存文章”进入独立管理页，可删除、拖拽排序、用上移/下移按钮排序、查看 Markdown 预览及确认开始新的检索。收藏独立保存在本机，不随生成缓存过期，最多 200 篇、4 MiB，达到上限明确报错而非淘汰旧条目。

导出在启动时固定当前顺序，生成一份 `articles.md`，含作者、年份、期刊、原摘要、译文、要点、来源、APA 风格引用和 BibTeX；原文文件命名为 `1-标题.pdf`、`2-标题.pdf` 等，同批次放入 `ScholarHover/时间-批次/` 下载子目录。拖拽整理后的顺序决定编号；后续修改列表不改变已开始的导出。

## 下载与引用边界

原文下载仅使用匹配记录的主要出版位置提供的 PDF 地址，不静默替换为另一个开放获取预印本。OpenAlex 对主要位置与开放版本位置的区分见[位置字段说明](https://help.openalex.org/data/locations/)。找不到直达 PDF 时，提示用户在原文页面获取。

Chrome 下载接口会使用原文站点已有 Cookie，扩展不传递模型或 OpenAlex 密钥；下载状态以浏览器报告为准，取得 downloadId 不代表完成。[Chrome downloads 接口](https://developer.chrome.com/docs/extensions/reference/api/downloads)提供启动、状态检查及失败信息。扩展不会自动接受危险下载警告。

返回 HTML 等明确非 PDF 响应时显示失败，并清理该批次刚创建的无效文件。服务器返回通用二进制类型或没有标明类型时，保留已下载文件并提示人工检查，不声称已经确认是 PDF。本版使用浏览器提供的 MIME 信息，不解析 PDF 字节内容。

每批次自动打开第一个失败条目的原文页面，其余失败项提供“打开原文 / 认证页面”链接，避免大量标签页同时弹出。登录、机构认证、付费与验证码由用户处理；认证后可明确重试，不会循环重试或绕过限制。没有 PDF 链接的条目需要在原文页面手动下载。

引用文本基于现有元数据，保留作者原名称；缺失卷期、页码不补造。BibTeX 使用通用 `misc` 类型，正式引用前需要核对出版物类型及格式。导出本身不会额外调用模型。

- 评估器回归、TypeScript 与生产构建通过。
- 构建后的真实 MV3 浏览器检查：73 项通过，零页面错误，证据 `test-results/e2e.json`，完成于 2026-09-16T03:19:28.170Z。
- 20 次本地缓存首帧采样 P95 为 6.3 ms（扣除 500 ms 悬停等待）；此结果不代表外部接口延迟。
- 最终 ZIP 的 25 个文件逐字节匹配 `dist`；管理页、下载权限、四语言元数据与校验和已检查。

原生下载验证没有替换 Chrome downloads API：使用临时浏览器配置、临时下载目录及本机 HTTP 测试服务器。5 次实际传输分别是 Markdown、两个成功 PDF、一个返回 HTML 的无效 PDF 和一次成功 PDF 重试。浏览器实际文件名保留 `1-`、`2-`、`4-` 编号；第 3 条没有 PDF 地址，未虚报成功。HTML 文件被清理，重试仍使用同一批次编号。

`test-results/exported-articles.md` 为 18,298 字节，与管理页预览逐字一致；`native-downloads.json` 保存实际文件名、状态与大小，`exported-sample.pdf` 为 608 字节的人工测试 PDF。已检查 `resized-sidebar.png`、`collection-downloads.png` 和 `collection-retry-complete.png`。测试覆盖原生拖拽排序、保存去重、删除、未生成字段、失败认证入口和显式重试；所有测试条目及模型响应均为夹具。

独立审查发现并修复了三个并发问题，并添加复现用例：收藏容量不足不能让成功生成的译文显示为生成失败；旧输出语言的迟到结果不能覆盖新语言收藏；保存与生成同时发生时不能漏存刚生成的译文。管理页也隔离了旧轮询响应，避免覆盖新的下载重试状态。调整边框自动固定时的状态文字已同步修正。

## 安装与复现

安装包：`release/scholar-hover-0.3.0.zip`。SHA-256：

```text
dd440e23981c4446509394616d489153e4fccb42ad16961c18f31881bc293963
```

升级时解压覆盖到原加载目录，在 `chrome://extensions` 重新加载扩展，并刷新 Scholar。0.3.0 新增 `downloads` 权限；本版保留已有设置、密钥规则和生成缓存。正常导出的文件不会随删除收藏、清空缓存或卸载扩展而删除。

```sh
npm test -- --reporter=json --outputFile=test-results/unit.json
npm run test:corpus
npm run build
npm run test:e2e
node scripts/package.mjs
```

验证环境为 macOS、Node.js 22.23.1、Vite 7.3.6、Playwright 1.62.1。使用隔离浏览器配置、离线 Scholar/API 夹具及本地测试文件服务器，没有使用用户密钥、访问真实 Scholar 或调用付费模型。真实出版商登录/机构认证、原生授权界面和翻译质量仍需用户试用；100 条 Scholar 人工核验和筛选效率研究尚未完成。
