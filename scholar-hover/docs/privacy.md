# 知阅 · 文献悬停助手隐私说明

版本 0.5.0（本地版本，尚未发布）· 2026-09-26

[English](privacy.en.md) · [Français](privacy.fr.md) · [Deutsch](privacy.de.md)

本插件默认关闭。用户在工具栏弹窗切为 ON 并明确授予所有 HTTPS 网站的可选 `https://*/*` 访问权限后，才在支持的 HTTPS 网页（包括 Google Scholar、Nature、arXiv）中读取悬停或聚焦链接的文字及目标 URL；Scholar 结果还提供已有论文字段。在悬停或聚焦 500 毫秒后查询该链接，未触发的链接不批量发送外部服务。支持的已打开网页无需刷新即可注入脚本，但 `chrome://`、Chrome 应用商店、内置 PDF 阅读器及限制扩展访问的页面不支持。关闭后停止新预览，保留已收藏内容，已发起任务可能继续完成。插件不自动搜索或翻页；原文下载仅由用户主动导出，不建立产品账号或自建服务器。

## 数据发送到哪里

- 原文网站：先按规范化后的精确目标 URL 检查本机归档，再请求用户触发链接的公开 HTML。同一 URL 的不同链接文字复用预览。开启悬停时授予的所有 HTTPS 网站权限也允许读取这些目标网站，不再仅申请当前出版社。arXiv 摘要、PDF、HTML 链接保留明确修订版；Nature 提取要求可核验论文身份与明确 Abstract 摘要区。引用元数据及明确的 `ScholarlyArticle` 摘要在本机解析。请求不携带 Cookie、登录凭据、OpenAlex Key 或模型 Key；整页不发送模型。普通网页描述不当作完整摘要，不提取任意 PDF 正文，不执行脚本、登录或跳转。
- OpenAlex：只对已识别的论文按 DOI 或核验标题查询补充信息，摘要补充须符合论文身份和发表类型；arXiv 稿件及明确修订版不由索引记录替换。没有论文元数据的任意链接不使用链接文字做索引标题搜索。填写 OpenAlex Key 时，Key 只发送 api.openalex.org。
- Crossref：回退查询中，必要时发送 DOI，补充同一论文的缺失摘要。
- 用户配置的模型服务：仅在完成配置并同意外发后，发送当前论文标题、取得的摘要和所选生成语言的翻译指令。无摘要时只发送标题及翻译指令，不生成摘要或概述。模型 API Key 只发送给用户配置的 HTTPS 服务地址；服务商自身的数据保留规则由其提供。
- 使用自动模式会在有效悬停后调用模型并可能产生费用；可切换为点击生成。主动点击“缓存本文”也会请求后台补全，即使悬停自动生成已关闭；模型调用仍需已有外发同意、有效 Key 和模型域名权限。已有匹配结果会复用。关闭卡片或网页标签页不取消已保存论文的补全任务，也不保证撤销服务商已开始的计费。

普通链接没有论文元数据时，仅主动点击才能翻译链接标题，不生成摘要。

界面语言和生成语言可分别选择简体中文、英语、法语或德语，默认均为简体中文。语言设置保存在本机。只改界面语言会继续复用生成缓存；不同生成语言使用不同缓存条目。原始论文信息不会被译文覆盖。

## 本机存储

密钥默认存储于扩展的浏览器会话存储，浏览器重启后清除。选择在本机保存密钥后，密钥保存到本机扩展存储；这不是系统密码保险库或加密保管承诺。密钥不写入网页、同步存储、分析统计或日志，网页内容脚本不能读取密钥存储。可以随时清除密钥。

论文预览信息、匹配候选及生成结果只保存在本机 IndexedDB 归档，不设置时间到期或 200 条 / 4 MiB 自动淘汰规则，仍受浏览器存储配额限制。同一论文的不同模型或生成语言结果分别保存，仅复用内容与配置指纹匹配的结果，不跨设备同步。升级到 0.4.0 时会迁移旧生成缓存，归档事务提交后才清理旧副本；迁移失败保留旧记录。无法识别的旧记录保留原始副本，不保证可以直接复用为译文。

0.4.1 会让符合条件的旧缺摘要预览（例如已存的 HTTP 429，且没有候选或人工确认）在再次打开时尝试新读取流程；完整摘要和可复用的付费译文保留。“重新读取摘要”重试原文查询，“重试生成”重试模型；取得新摘要后，旧标题译文不再满足新输入。取得摘要后的模型调用仍遵循用户生成设置、外发同意和配置，收藏失败则可手动重试补全。

“清空缓存”清除预览与生成归档，“清除密钥”仅处理密钥；独立收藏需另行删除或清空。卸载扩展会删除其本机存储，浏览器清理数据或存储故障也可能影响归档，因此归档不等于备份。上述操作不能删除服务商已经接收的数据。

## 权限与控制

首次安装或首次从 0.4.x 升级后悬停开关为 OFF；之后重新加载或重启浏览器会保留开关状态。工具栏切为 ON 时 Chrome 申请所有 HTTPS 网站的可选 `https://*/*` 权限，用于读取悬停链接文字及其目标元数据；安装本身不授予该范围。OFF 停止新预览，保留收藏，已发起任务可能继续完成；如要撤销已授予的网站权限，请在 Chrome 扩展设置中操作。OpenAlex、Crossref 用于论文元数据补充，模型域名在配置中管理；全 HTTPS 授权可覆盖模型域名访问，但不会替代模型外发同意。`offscreen` 用于等待模型回复与在扩展隐藏页本地解析公开 HTML，不执行原文脚本，不把整个网页交给模型。模型 Key 只发往配置地址，密钥不写入网页。

本版本不含广告、自动遥测或后台使用记录上传。测试诊断仅保存到本地；分享诊断前应自行检查。模型输出可能出错，摘要译文和概述均标注依据，不能作为论文全文结论或质量评分。真实页面试用、四种语言的人工与母语使用者审核，以及文献筛选效果的用户对照验证尚未完成。

本文描述尚未公开发布的本地 0.5.0 版本；公开下载仍为 [0.4.0 开源试验版](https://github.com/Jerrywjr/scholar-hover/releases/tag/v0.4.0)。反馈渠道为 [GitHub Issues](https://github.com/Jerrywjr/scholar-hover/issues)。项目尚未提交或上架 Chrome Web Store，发布时须同步公开隐私说明。验证边界见 [0.5.0 测试报告](test-report-0.5.0.md)：浏览器测试预先授予 HTTPS 权限，不证明真实 Chrome 权限对话框已经验证。

## 主动缓存、后台补全与导出

点击“缓存本文”先把已有页面信息写入独立本机收藏，保存成功后再排队核对论文、查找摘要并按已有模型配置补全译文。收藏最多 200 篇、4 MiB，无自动到期；直到用户删除条目、清空列表或卸载扩展。清空预览与生成归档不影响这份收藏。重复保存保持首次顺序，不会重启失败任务；后续结果只更新仍存在且源内容相符的收藏。

浏览器运行时，关闭网页标签页后补全继续。浏览器或扩展后台重启后，排队与元数据查询阶段可恢复；已进入模型生成的任务先查找可复用结果，没有结果则标为“已中断”，需人工重试，因为上次请求可能已计费。模型失败不自动重试；缺少配置时等待用户处理，候选不确定时等待用户确认。浏览器重启后，未选择本机保留的会话 Key 需要重新填写。

在管理页主动发起 Markdown 与原文导出后，使用 downloads 权限生成 Markdown 文件并尝试下载已知的原文 PDF。未完成的条目也可导出，界面会提示，缺失字段保持标记；导出固定当时内容，之后补全不改写已导出的文件。请求发送到原文提供方，Chrome 会携带该站点已有的 Cookie；模型和 OpenAlex 密钥不会发送给原文站点。原文不发送给模型分析。下载失败或无法取得 PDF 时，会提示原因并自动打开本批次第一个失败条目的原文页面，其他条目可逐一打开；登录、机构认证和验证码由用户完成。

最新批次的文件名、原文链接及下载状态保存在本机，用于核对和重试。返回非 PDF 的下载不会标为成功，并尝试删除该批次刚创建的无效文件。正常导出的文件保存在浏览器下载目录；删除收藏、清空生成缓存或卸载插件不会删除这些导出文件。后台补全仅按上述规则请求原文网站、元数据及模型服务，不上传使用历史或遥测。
