# 知阅 · 文献悬停助手隐私说明

版本 0.2.0 · 2026-09-15

[English](privacy.en.md) · [Français](privacy.fr.md) · [Deutsch](privacy.de.md)

本插件仅增强用户打开的 https://scholar.google.com/scholar 搜索结果页。它读取被触发的结果标题、作者、年份、发表载体和链接，用于识别论文；不自动搜索、翻页或获取全文，不建立产品账号或自建服务器。

## 数据发送到哪里

- OpenAlex：被触发论文的 DOI 或标题，用于补全元数据与摘要。填写 OpenAlex Key 时，Key 只发送给 api.openalex.org。
- Crossref：必要时发送 DOI，补充同一论文的缺失元数据。
- 用户配置的模型服务：仅在完成配置并同意外发后，发送当前论文标题、取得的摘要和所选生成语言的翻译指令。无摘要时只发送标题及翻译指令，不生成摘要或概述。模型 API Key 只发送给用户配置的 HTTPS 服务地址；服务商自身的数据保留规则由其提供。
- 使用自动模式会在有效悬停后调用模型并可能产生费用；可切换为点击生成。取消界面不保证撤销服务商已开始的计费。

界面语言和生成语言可分别选择简体中文、英语、法语或德语，默认均为简体中文。语言设置保存在本机。只改界面语言会继续复用生成缓存；不同生成语言使用不同缓存条目。原始论文信息不会被译文覆盖。

## 本机存储

密钥默认存储于扩展的浏览器会话存储，浏览器重启后清除。选择在本机保存密钥后，密钥保存到本机扩展存储；这不是系统密码保险库或加密保管承诺。密钥不写入网页、同步存储、分析统计或日志，网页内容脚本不能读取密钥存储。可以随时清除密钥。

论文数据及生成结果只缓存在本机，生成缓存最多保留 200 条记录、7 天、4 MiB；同一论文的不同模型或生成语言结果分别占用条目。清空缓存、清除密钥和卸载插件均有相应本机删除效果，不能删除服务商已经接收的数据。

## 权限与控制

仅在 Scholar 论文搜索页运行。OpenAlex 和 Crossref 为元数据访问权限；自定义模型域名在用户保存配置时单独请求授权。清单中的可选 HTTPS 域名范围用于支持用户自定义地址，不会在安装时取得所有网站访问权限。

本版本不含广告、自动遥测或后台使用记录上传。测试诊断仅保存到本地；分享诊断前应自行检查。模型输出可能出错，摘要译文和概述均标注依据，不能作为论文全文结论或质量评分。真实页面试用及四种语言的人工、母语使用者审核尚未完成。

本测试包尚未公开发布，GitHub 公开发布等待用户试用后的明确确认。正式商店发布前，发布者必须在商店页面提供可用的联系渠道和本隐私说明的公开地址。
